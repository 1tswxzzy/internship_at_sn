# 中小学教育台账指标分析工具（实习项目）

实习期间开发的 Excel 报表自动化处理脚本，用于批量分析地方教育局「中小学分校一览表」采集数据，按**优质均衡**指标口径完成指标换算、特殊学校学段拆分、分校区合并与区县差异系数统计。

项目在**统信 UOS**（基于 Linux 的国产操作系统，ARM64 平台）环境下交付使用，最终以单一可执行程序形式分发给非技术岗位的办公人员一键运行。

> 项目为跨科室合作：表格解析框架与区县统计部分由合作同事参与完成，本人负责框架重构、指标计算、特殊学校处理、打包与交付。

---

## 一、功能概览

### 1. 七项指标计算

| # | 指标 | 口径 | 是否需要学段占比调整 |
|---|------|------|:---:|
| 1 | 每百名学生多媒体教室数 | 每百名 | ✅ |
| 2 | 每百名学生高学历教师数 | 每百名 | — |
| 3 | 每百名学生骨干教师数 | 每百名 | — |
| 4 | 每百名学生艺体教师数 | 每百名 | — |
| 5 | 生均教学及辅助用房面积 | 生均 | ✅ |
| 6 | 生均运动场馆面积 | 生均 | ✅ |
| 7 | 生均教学仪器设备值 | 生均（万元 → 元） | ✅ |

### 2. 特殊学校学段占比拆分

九年一贯制、十二年一贯制、完全中学同时跨越多个学段，其校舍、场地、设备等资源需要按学段拆分后再计入指标。脚本跨「小学 / 初中 / 高中」三个文件查找同一所学校，按权重计算各学段占比：

| 学校类型 | 学段权重 |
|----------|----------|
| 九年一贯制 | 小学 1、初中 1.1 |
| 十二年一贯制 | 小学 1、初中 1.1、高中 1.32 |
| 完全中学 | 初中 1、高中 1.2 |

### 3. 分校区合并（`是否计校数` 标签）

采集表中部分「基点校 / 村小 / 教学点」不计入校数（标签为 `0`）。脚本先挂起这些行，待整表读完后**逐条提示**：

```
发现不计校数的学校：某基点校 (行 68)
请输入该校所属的原校点名称（严格匹配学校名称）：
```

用户按表内学校名称严格输入归属的主校点后，两条数据相加，结果合并到主校点名下再参与计算。

### 4. 区县差异系数统计

按「统计三级」列将学校划入区县分组，逐指标计算平均值、标准差与差异系数，输出区县差异系数统计表与区县汇总表。

## 二、核心算法

### 表头与列的自动定位

采集表是多级表头、列序不固定（且不同年度、不同学段的表结构有差异），脚本不硬编码列号，而是：

- `guess_head_size()` —— 探测表头占用行数，并允许用户回车确认或手动输入覆盖；
- `find_col_by_keywords()` —— 按关键词定位列，支持 `any` / `all` / `sum` 匹配模式；
- `find_col_by_hierarchy()` —— 按多级表头层级路径定位（如 `['在校生数', '合计']`）；
- `find_cols_with_prefix()` —— 定位某个表头前缀下的连续列区（如「专任教师 → #按学历分」）；
- `find_high_education_cols()` —— 按学段区分策略定位（研究生 / 本科）学历列。

### 指标换算

```
调整后指标数 = 原始指标数 × 学段占比
每百名类：调整后指标值 = 调整后指标数 × 100 / 在校生数
生均类  ：调整后指标值 = 调整后指标数 / 在校生数
          （教学仪器设备值先由万元换算为元：× 10000）
```

### 区县差异系数

```
X（平均值） = Σ(调整后指标数 × multiplier) / Σ(在校生数)
方差        = Σ(A_i / A_sum) × (调整后指标值_i − X)²
差异系数    = 标准差 / X
```

其中每百名类指标 `multiplier = 100`，生均类指标 `multiplier = 1`。

## 三、运行方式

脚本为**交互式**命令行程序，依次提示输入小学、初中、高中三个采集表路径：

```bash
python 12.py
# 请输入小学的 Excel 文件路径： <路径>/分析教基1002_小学分校一览表_采集.xlsx
# 请输入初中的 Excel 文件路径： ...
# 请输入高中的 Excel 文件路径： ...
```

随后对每个文件弹出计算菜单：

```
请选择计算项目：
  1. 每百名学生多媒体教室数（需要调整）
  2. 每百名学生高学历教师数
  3. 每百名学生骨干教师数
  4. 每百名学生艺体教师数
  5. 生均教学及辅助用房面积（需要调整）
  6. 生均运动场馆面积（需要调整）
  7. 生均教学仪器设备值（需要调整）
  8. 一键执行以上全部
  9. 区县差异系数与汇总统计
  0. 完成此文件，生成报告
```

结果写回源文件同目录下的 `*_分析结果.xlsx`，包含各指标明细 sheet、区县差异系数统计 sheet、区县汇总 sheet 与学段占比分析 sheet。

**依赖**：Python 3.7+、`numpy`、`pandas`、`openpyxl`

```bash
pip install numpy pandas openpyxl
```

## 七、数据与隐私说明

- 本项目**不包含任何原始采集数据**。教育局台账采集文件（`分析教基1002/1003/1004_*分校一览表*` 等）以及脚本生成的 `*_分析结果.xlsx`，均已通过 `.gitignore` 排除，不会上传。
- 文档中涉及的具体学校名称、区县名称已做**脱敏处理**，统一以「某基点校 / 某中心校 / 某区县」等占位符替代，仅保留技术说明。
- 采集表字段列名（如「在校生数」「网络多媒体教室」「是否计校数」「统计三级」等）属于教育统计报表的通用字段，予以保留以便说明脚本逻辑。
- 仓库中不包含任何 API Key、Token 或凭据文件，`.gitignore` 已对常见凭据文件名与 `1/` 数据目录做拦截。
